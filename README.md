# TTU Marketplace - Create Listing

**Alex Long | Alpha 2 | ENGR 1340**

This is my Create Listing page for our TTU Marketplace project. It has the form someone would use to list an item for sale.

[Open the page](https://syphrixer1.github.io/TTU-Create-Listing-Alpha2/)

[My individual progress report](reports/Alex_Long_Individual_Report.docx)

## What works so far

The form has fields for the item's title, description, condition, price, and pictures. The required fields need to be filled out before Create works. Choosing pictures shows how many files were selected, and Cancel clears the form.

The example listings on the right show what other items could look like. Create shows a message for now. It doesn't save or post the item yet.
