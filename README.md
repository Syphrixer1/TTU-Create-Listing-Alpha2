## Scope

This separate repository contains only the Create Listing interface, its stylesheet and image assets, and Alex's individual report. It does not contain the team's Home, About, Listings, Account, Cart, or Checkout pages. The original group repository remains unchanged.

## Page responsibility

Alex Long — Create Listing / data-entry form. The HTML file identifies Alex at the top. Its form includes labeled title, description, condition, price, and image fields. The condition choices use radio buttons; the price is a number input with a nonnegative minimum. Selected files update an image count. Create validates the form and displays a preview message. Cancel resets the form. The sample listing cards are visual examples, not additional pages.

## File structure

- `index.html` — the Create Listing page and GitHub Pages entry point
- `css/styles.css` — all styling, including responsive layout and focus states
- `images/` — five SVG icons and sample-item images
- `reports/Alex_Long_Individual_Report.docx` — Alex's 150–200 word report with a current browser screenshot

## Development

Open this folder in VS Code and use Live Server or open `index.html`. The page works without installing packages. It does not publish listings or upload images to a service. GitHub Pages publishes `main`; Alex's individual development branch is `Alex's-Page`.
